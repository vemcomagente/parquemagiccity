# Passeio Magic City

Página do passeio escolar da **Saint Mary's School** ao **Magic City Parque Aquático**, em **22/10/2026**, organizado pela **Vem com a Gente Viagens**.

Site estático (HTML e CSS), sem instalação e sem etapa de build.

## Estrutura

```
index.html      Página principal: cronograma, parque, combo Magic Burger, dúvidas e o que levar
css/estilo.css  Cores, fontes e layout
img/            Logos
```

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub (por exemplo, `magiccity`).
2. Em **Add file > Upload files**, arraste **tudo o que está dentro da pasta** (`index.html`, `README.md`, `css` e `img`). Não envie o `.zip`.
3. Clique em **Commit changes**.
4. Em **Settings > Pages**, escolha **Deploy from a branch**, a branch `main` e a pasta `/ (root)`, e salve.
5. O endereço aparece na mesma página em alguns minutos.

O `index.html` precisa ficar na raiz, e as pastas devem manter os nomes.

## Como alterar

Horários e textos ficam no `index.html`. Para trocar um logo, substitua o arquivo em `img/` mantendo o mesmo nome. As fontes vêm do Google Fonts e precisam de internet.
